# Ergovida Centro Médico

Website estático para GitHub Pages. Abra `index.html` localmente ou publique esta pasta num repositório GitHub e active **Settings → Pages → Deploy from branch**.

## Antes de publicar

1. Substitua `SEU-UTILIZADOR` e `SEU-REPOSITORIO` no `index.html`, `robots.txt` e `sitemap.xml` pelo endereço final.
2. Configure um serviço de formulários seguro (Formspree, Web3Forms ou equivalente) no campo `formEndpoint` de `js/config.js`. Não coloque credenciais no website.
3. Confirme o link oficial do Instagram e preencha `instagramUrl` em `js/config.js`.
4. Confirme com a clínica horários, identidade final e eventuais fotografias/biografias adicionais.

Os números, email, morada, equipa e serviços presentes foram incluídos apenas quando fornecidos no Portfólio Ergovida 2026. Não foram criados horários, especialidades adicionais, testemunhos ou redes sociais.
